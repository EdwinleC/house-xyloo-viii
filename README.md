# House Xyloo VIII

A mobile-first guest landing page designed to be opened from the NFC tag at the entrance.

## Edit these 3 things before publishing

Open `index.html` and replace:

1. `YOUR_WIFI_NAME`
2. `YOUR_WIFI_PASSWORD`
3. `YOUR_PLAYLIST_LINK`

There are two occurrences of the Wi-Fi placeholders in the visible page and one playlist URL.

## Publish with GitHub Pages

1. Create a new public GitHub repository (for example `house-xyloo-viii`).
2. Upload **all files and the `assets` folder** from this project to the root of the repository.
3. Commit the files.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will provide the public Pages URL after deployment.
8. Write that public URL to the NFC tag as a normal URL/URI record.

Anyone scanning the NFC tag can then open the page in their browser. They do not need Apple Shortcuts.

## Security note

Use a guest Wi-Fi network rather than your primary network if the password is going to be displayed on a public web page.
